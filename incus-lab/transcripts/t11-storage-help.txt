$ ./incus storage --help --sub-commands
Description:
  Manage storage pools and volumes

Usage:
  incus storage [flags]
  incus storage [command]

Available Commands:
  bucket       Manage storage buckets
    create       Create new custom storage buckets
    delete       Delete storage buckets
    edit         Edit storage bucket configurations as YAML
    export       Export storage bucket
    get          Get values for storage bucket configuration keys
    import       Import storage bucket
    key          Manage storage bucket keys
      create       Create key for a storage bucket
      delete       Delete key from a storage bucket
      edit         Edit storage bucket key as YAML
      list         List storage bucket keys
      show         Show storage bucket key configurations
    list         List storage buckets
    set          Set storage bucket configuration keys
    show         Show storage bucket configurations
    unset        Unset storage bucket configuration keys
  create       Create storage pools
  delete       Delete storage pools
  edit         Edit storage pool configurations as YAML
  get          Get values for storage pool configuration keys
  info         Show useful information about storage pools
  list         List available storage pools
  set          Set storage pool configuration keys
  show         Show storage pool configurations and resources
  unset        Unset storage pool configuration keys
  volume       Manage storage volumes
    attach          Attach new custom storage volumes to instances
    attach-profile  Attach new custom storage volumes to profiles
    bitmap          Manage storage volume dirty bitmaps
      create       Create a dirty bitmap on a storage volume
      delete       Delete storage volume dirty bitmaps
      list         List storage volume dirty bitmaps
      show         Show storage volume dirty bitmap information
    copy            Copy custom storage volumes
    create          Create new custom storage volumes
    delete          Delete custom storage volumes
    detach          Detach custom storage volumes from instances
    detach-profile  Detach custom storage volumes from profiles
    edit            Edit storage volume configurations as YAML
    export          Export custom storage volumes
    file            Manage files in custom volumes
      create       Create files and directories in custom vollume
      delete       Delete files in custom volume
      edit         Edit files in storage volumes
      mount        Mount files from custom storage volumes
      pull         Pull files from custom volumes
      push         Push files into custom volumes
    get             Get values for storage volume configuration keys
    import          Import custom storage volumes
    info            Show storage volume state information
    list            List storage volumes
    move            Move custom storage volumes between pools
    nbd             NBD access to a block storage volume
    rebuild         Rebuild custom storage volumes
    rename          Rename custom storage volumes
    set             Set storage volume configuration keys
    show            Show storage volume configurations
    snapshot        Manage storage volume snapshots
      create       Snapshot storage volumes
      delete       Delete storage volume snapshots
      list         List storage volume snapshots
      rename       Rename storage volume snapshots
      restore      Restore storage volume snapshots
      show         Show storage volume snapshot configurations
    unset           Unset storage volume configuration keys

Global Flags:
      --debug          Show all debug messages
      --explain        If the command is valid, explain its parsed arguments instead of running it
      --force-local    Force using the local unix socket
  -h, --help           Print help

  -q, --quiet          Don't show progress information
      --sub-commands   Use with help or --help to view sub-commands

      --version        Print version number
